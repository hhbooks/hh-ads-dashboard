    🔗 Kết Nối API & Đồng Bộ ADS ▶

    Bước 1: Bấm Kết Nối từng shop — Shopee sẽ yêu cầu đăng nhập, sau đó tự động lưu token về hệ thống. Chỉ làm 1 lần, token tự refresh về sau.
    Bước 2: Mỗi ngày bấm Đồng Bộ ADS để kéo data về Dashboard — không cần vào Shopee nữa.

    ⚠️ Quan trọng — Shopee chọn shop theo phiên đăng nhập trên open.shopee.com, KHÔNG theo nút bạn bấm: trang xác thực nằm trên open.shopee.com (dùng chung phiên với Open Platform Console, khác hoàn toàn với Seller Centre banhang.shopee.vn). Nếu trình duyệt đang đăng nhập sẵn Console/open.shopee.com bằng tài khoản shop nào, mọi lần Kết Nối đều bị tự xác nhận cho shop đó mà không hỏi lại.
    👉 Cách kết nối đúng shop: mở cửa sổ ẩn danh → vào Dashboard này → bấm Kết Nối shop cần kết nối → Shopee sẽ hiện màn đăng nhập ("Login to Authorize Shopee Openplatform APP") → đăng nhập bằng tài khoản của đúng shop đó → xác nhận. Lặp lại từng shop (mỗi shop 1 cửa sổ ẩn danh mới, hoặc đăng xuất open.shopee.com giữa các lần). Nếu lỡ kết nối lệch, hệ thống sẽ báo ngay và token vẫn lưu đúng theo shop Shopee thực trả về (không lưu nhầm).

    Xử Lý File Eligible Product List (Đăng Ký Khung Giờ / Flash Sale)

    Upload file Eligible Product List (tải từ Shopee xuống) và file Map Salework (DS_SanPham_MAP_Salework...xlsx). Hệ thống map theo Mã phân loại hàng ↔ Mã Salework liên kết (kể cả combo), tra giá bán trong Danh Mục SKU (đồng bộ từ Google Sheet "Trung Tâm Dữ Liệu") để điền cột Giá khuyến mãi. Cột Kho hàng dự trữ cho khuyến mãi = Kho hàng ÷ 2 (làm tròn xuống), cột Giới hạn mua hàng = bằng Kho hàng dự trữ. Bảng hiển thị đầy đủ để bạn xem trước — chỉ xuất file khi bạn quyết định.
